# InvEx

## Sistema de Gestión de Inventarios y Ventas B2B

Proyecto desarrollado para el programa de Análisis y Desarrollo de Software del SENA.

## Estructura del proyecto

- backend: espacio destinado al desarrollo del servidor.
- frontend: espacio destinado al desarrollo de la interfaz del sistema.

## Proyecto

InvEx busca facilitar la gestión de inventarios, productos, ventas, clientes y proveedores para pequeñas y medianas empresas.
